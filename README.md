# ⚔️ سكربت Multi-Game Delta Hub [PROTECTED v4.0 - World 5: The Sunken Depths / CHRONOS]

سكربت شامل ومحمي بالكامل يعمل عبر **رابط واحد فقط** مع **الكشف التلقائي عن اللعبة وعزل القوائم تلقائياً (Strict Per-Game UI Isolation)** على مشغل **Delta Executor** (أندرويد، iOS، وكمبيوتر):
1. **🗡️ Pixel Blade (تحديث World 5: The Sunken Depths / بداية Arc 2 وحدث CHRONOS — v4.0)**:
   - عند فتح السكربت داخل **Pixel Blade** تظهر **فقط** تبويبات Pixel Blade ويعمل كل من **الفارم التلقائي، الهالة (Kill Aura)، تكسير الصناديق، اختيار الترقيات، وفتح الصناديق** تلقائياً فور التشغيل.
   - **محرك v4.0 الذكي لمنع القفز المبكر لغرفة البوس + القتل الفوري بدون لاق**:
     - **حل جذري لمشكلة الانتقال لساحة البوس بعد الغرفة الأولى (`Anti-Boss-Jump & Sequential Room Engine`)**:
       - تثبيت نقطة القياس على آخر غرفة نشطة (`State.PB_LastActiveRoomPos`) بدلاً من موقع اللاعب المؤقت، مع إعطاء مهلة `1.6s` بعد تنظيف الغرفة لظهور وحوش الغرفة التالية وإعادة فحص الأهداف بعد الانتظار.
       - تفضيل الغرف المرقمة المتسلسلة (`"2"`, `"3"`, `"4"`, `"5"`, ...) والأعداء غير الزعماء القريبين (`<= 320 studs`) وعدم القفز إلى البوس المحمّل مسبقاً في نهاية الدنجن (`hadEntrance == false`) قبل الوصول إلى غرفته.
       - **نظام الاسترداد التلقائي (`Locked-Mob Auto-Recovery`)**: إذا انتقل اللاعب لأي عدو في غرفة مقفلة (`hadEntrance == false`) ولم ينقص دمه خلال `2.6` ثانية، يقوم السكربت باستبعاده مؤقتاً وإرجاع اللاعب فوراً إلى مسار الغرف الصحيح.
     - **إعادة الضرر الفوري القاتل من مسافة قريبة (`3.8 studs` + `tornado` قبل `abilityHit`):**
       - تقريب المسافة خلف العدو إلى `3.8 studs` بارتفاع مستوٍ (`Y = 0.5`) لتتطابق مع فحص مدى السيف في السيرفر (`onHit`).
       - إقران `useAbility("tornado")` مباشرة قبل `abilityHit(math.huge)` و`onHit` مع تفعيل الباف الثلاثي (`999,999,999%` + `5.5B%` + `5000 Poison`) على كلٍّ من `rawChar` و`Character` لضمان القتل الفوري مع الحفاظ على خفة الأداء بدون لاق.
   - **🎣 صيد تلقائي تيربو بالصنارة (Turbo Auto Fishing)**:
     - تفاعل فوري **60 مرة في الثانية (`RenderStepped`)** مع ميني جيم الصيد (الضغط المستمر للدائرة الخضراء + النقر التيربو السريع للسحب الأزرق).
